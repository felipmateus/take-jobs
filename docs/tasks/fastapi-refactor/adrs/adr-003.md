# ADR-003: One spider per source walking all terms

## Status

Accepted (user approval of the spec, 2026-10-30)

## Date

2026-10-30

## Context

The PRD caps requests at 1 per second per site. Scrapy applies `DOWNLOAD_DELAY` and `CONCURRENT_REQUESTS_PER_DOMAIN` per download slot, and each crawler has its own downloader. Running one crawler per term (v1 style: `scrapy crawl vagas -a search=…`, with 12 terms in parallel) would send up to 12 concurrent requests to the same site.

## Decision

Each source has exactly one spider class, which receives the full term list and issues the first-page request for every term itself. A single `CrawlerProcess` runs one crawler per registered source; the two sites are crawled in parallel. Settings: `CONCURRENT_REQUESTS_PER_DOMAIN=1`, `DOWNLOAD_DELAY=SCRAPE_DOWNLOAD_DELAY`, `RANDOMIZE_DOWNLOAD_DELAY=False`, `AUTOTHROTTLE_ENABLED=False`, `ROBOTSTXT_OBEY=True`. The spider tracks seen ids, page count and error per term, which implements stop rule 17 and US-005.

## Alternatives Considered

### Alternative 1: One crawler per term, run sequentially

- **Pros:** simplest spider, which takes one term.
- **Cons:** 12 × 2 crawlers; the per-site rate still holds only if runs are fully sequential, which roughly doubles total time because the two sites can no longer overlap.
- **Why rejected:** slower, and the rate limit depends on orchestration rather than configuration.

### Alternative 2: One crawler per term in parallel with a global rate limiter

- **Pros:** parallel terms.
- **Cons:** a custom cross-crawler throttling middleware; it violates the spirit of 1 req/s per site anyway if misconfigured.
- **Why rejected:** custom code for a constraint Scrapy already enforces per crawler.

## Consequences

### Positive

- The rate limit is a property of standard Scrapy settings.
- A run takes about 4–8 minutes.

### Negative

- The spider manages per-term state (seen ids, pages, error) instead of being stateless per term.

### Risks

- Per-term state bugs could cross terms. This is covered by the spider unit tests (UT-040–UT-047).
